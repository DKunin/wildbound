# Контракт глубины объектов окружения

- Runtime-задача: сохранить читаемость волка и других животных рядом с объектами окружения.
- Движок: Phaser 3.90; камера сверху; плавно отрисованные PNG с альфа-каналом.
- Семейство: `terrain-features-v4.png` и `obstacle-atlas-v3.png`, сетка 4×4 по 313×313 пикселей, центральный origin.
- Источник: существующие оригинальные атласы проекта (`art_source=existing`).
- Всегда под животными: бурелом, лежащие брёвна, мелкие камни и ветви.
- Сортируются по положению: деревья, саженцы, валуны, скальные выходы, гранитные осыпи и утёсы.
- Инварианты: коллизии, навигация, геометрия, масштаб, альфа-канал и номера кадров не меняются; снижение цветности палитры выполнено одинаковым детерминированным преобразованием для всего семейства.
- Проверка: Agent Sprite Forge sheet QA, тесты политики глубины и просмотр сцены в Phaser при игровом масштабе.
- Атласы нормализованы до точного размера 1252×1252. Связные элементы перепаковываются в тот кадр, которому принадлежит большая часть элемента, а однопиксельное прозрачное поле отделяет соседние кадры. Поэтому сетка Sprite Forge совпадает со срезами Phaser и проверки пересечения кадров проходят без потери крайних частей объектов.
- Воспроизводимые команды: `npm run sprites:terrain-muted` создаёт приглушённые версии без изменения альфа-канала, затем `npm run sprites:world-grid` нормализует runtime-сетку. Тест `WorldAtlasArtwork.test.ts` фиксирует размеры, заполненность кадров, прозрачные границы, снижение цветности всего семейства и синхронность исходника `terrain-features-v4` с runtime-атласом.

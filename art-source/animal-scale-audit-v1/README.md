# Аудит масштаба состояний животных

Источник арта: `existing`. Цель — фиксированные RGBA-ячейки Phaser 3.90 без изменения игрового масштаба объекта: 346×284 для волков и 181×181 для добычи.

`npm run sprites:state-scales` применяет один коэффициент площади видимого корпуса ко всей последовательности действия управляемого волка и сохраняет прежнюю опорную точку. `npm run sprites:animal-actions` тем же способом приводит исходные позы отдыха, кормления и питья кролика, оленя, вапити и кабана к ожиданию того же направления до генерации четырёх фаз. Производные атласы переноски, закапывания и ран пересобираются после базовых листов.

`npm run audit:animations -- --fail-on-hard` проверяет 1600 runtime-циклов и 1424 чередования состояний. Из них 424 сопоставимые полнокорпусные пары автоматически ограничены линейным скачком масштаба 1.08; сжатые стойки, лежание, смерть, ответные действия и эффекты остаются визуальными проверками. Итог: 1424 перехода прошли, предупреждений и ошибок масштаба нет.

После нормализации диапазон линейного отношения к ожиданию у сопоставимых действий: управляемый волк 1.001–1.003, кролик 1.013–1.031, олень 1.020–1.041, вапити 0.997–1.019, кабан 0.995–1.020, Нива и Торр 0.982–1.000. Размеры ячеек, идентичность, линия земли и внутренняя пластика последовательностей сохранены.

## Sprite Forge QA

`sheet_qc.py frames` проверен на южном питье управляемого волка и четырёх видов добычи, а также на кормлении Нивы и Торра. Ошибок нет. Опубликованные предупреждения сохранены без подавления:

- `player-south-drink`: `near_duplicates`, пары `[[1,2],[3,4],[3,5],[4,5]]`, порог `0.95`.
- `rabbit-south-drink`: `near_duplicates`, пары `[[0,1],[0,2],[0,3],[1,2],[1,3],[2,3]]`, порог `0.95`.
- `deer-south-drink`: `near_duplicates`, пары `[[0,1],[0,3],[1,2],[1,3]]`, порог `0.95`.
- `elk-south-drink`: `near_duplicates`, пары `[[0,1],[0,3],[1,2],[1,3],[2,3]]`, порог `0.95`.
- `boar-south-drink`: `near_duplicates`, пары `[[0,1],[0,3],[1,2],[1,3],[2,3]]`, порог `0.95`.
- `niva-down-right-feed`: `near_duplicates` для `[[0,2]]` при пороге `0.95`; `torso_drift` `6.76` при пороге `2` пикселя.
- `torr-down-right-feed`: `near_duplicates` для `[[0,2]]` при пороге `0.95`; `torso_drift` `5.05` при пороге `2` пикселя.

Повтор кадра 0 в позициях 0 и 2 задан runtime-последовательностью кормления стаи. Остальные близкие пары — намеренно тонкие движения головы в спокойных циклах; проектная проверка отдельно требует не менее трёх уникальных фаз и достаточное семантическое движение. Горизонтальный дрейф корпуса у Нивы и Торра относится к наклону в кормлении, не к скачку масштаба или линии земли.

Полные числа, методы и ограничения находятся в каждом `sprite-forge-*/sheet-qc.json`; соответствующий `frames-review.png` хранит обзорную доску. `doctor.json` фиксирует доступные инструменты, а `player-normalization.json` — воспроизводимость преобразования управляемого волка.

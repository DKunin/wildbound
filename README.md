# Wildbound

Оригинальный браузерный симулятор выживания волка. Лесная территория создаётся детерминированно из текстурных слоёв и занимает 10240×10240 игровых единиц: поляны, лесная подстилка, связная сеть прямых, диагональных и поворотных троп, основная река с вертикальными, горизонтальными и диагональными участками, два отдельных ручья, двенадцать стоячих лесных луж трёх размерных классов, гранитные осыпи, заболоченные луга, ягодники, бурелом, деревья, берёзовые группы, валуны, скальные выходы, поваленные стволы и горные границы образуют связный мир вместо единого фонового изображения. Диагональные сегменты русла вытянуты до расстояния между центрами соседних клеток и слегка перекрываются, поэтому вода и берега соединяются без квадратных просветов. Течение подчёркнуто лёгкими бликами, которые медленно движутся вдоль русла. Деревья, молодая поросль, кустарник, камыш и вода получают едва заметное движение только в радиусе 1200 единиц от волка; пространственные корзины и обновление с частотой 10 Гц не анимируют остальной мир. Палитра земли и декораций приглушена, чтобы силуэты животных читались увереннее, а ночь добавляет мягкий синий тон без сильного затемнения. Неровные берега луж смешиваются с почвой, камнями и растительностью окружающей клетки, а крупные водоёмы иногда получают кувшинки. Между крупными препятствиями встречаются проходимые молодые деревья, кустарник, каменные россыпи, цветочные пятна и ветви. Положение водоёмов зависит от семени мира, а питьё и запах воды работают у каждого источника. Только река и ручьи создают слуховую подсказку: вода в лужах не течёт и остаётся беззвучной. Следы, звуки и запахи помогают читать окружающую среду. Логика двух сородичей сохранена, но временно отключена флагом функции; в активной симуляции участвует только управляемый волк. Охотники намеренно не добавлены.

Вапити добавлен как третий полноценный вид добычи: в `SURVIVAL` живут 5 особей, в `EXPLORER` — 10. Он использует собственные восьминаправленные циклы движения, отдыха, кормления и питья, оставляет тяжёлые следы и запах, имеет отдельные потребности, выносливость и тушу. Добыча больше не останавливается, пока продолжает видеть преследующего волка, сохраняет память об угрозе двенадцать секунд и продолжает наращивать дистанцию до видового безопасного порога. Истощение реально снижает скорость, а темп анимации бега синхронно замедляется, поэтому накопленную усталость теперь видно. При полном отдыхе экран гаснет, симуляция продвигается под чёрной шторкой и проявляется уже в новом времени суток.

Кабан добавлен как четвёртый вид добычи: 4 особи в `SURVIVAL` и 8 в `EXPLORER`. Семейные группы держатся ближе к влажному лесу, берегам, укрытиям и ягодникам, отдыхают днём и активнее кормятся вечером и ночью. При обнаружении волка кабан обычно уходит бегством; короткая защитная контратака возможна только при близком контакте и зависит от направления угрозы, ранения и поддержки группы. Для вида подготовлены оригинальные восьминаправленные атласы ожидания, ходьбы, бега, отдыха, кормления, питья и туши, а защитный рывок использует отдельный четырёхфазный цикл с опущенной головой вместо кадров бегства.

## Играть в браузере

[Открыть Wildbound](https://wildbound.kunini.ru/)

![Игровой процесс Wildbound: волк у лесного ручья](Screenshot%202026-10-17%20at%2010.20.34.png)

1. Откройте игру, выберите режим и нажмите `START`.
2. Перемещайтесь `WASD`; удерживайте `Shift` для рывка и `C` для скрытности.
3. Следуйте запахам клавишей `Q`, охотьтесь и взаимодействуйте с миром клавишей `E`.

## Запуск

```bash
npm install
npm run dev
```

Для проверки периферийного интерфейса чувств откройте `http://localhost:5173/?debug=senses`. Режим `SENSES LAB` не запускает симуляцию и не читает и не изменяет сохранение: он показывает все девять типов источников в восьми фиксированных направлениях, позволяет отдельно проверить запах, слух и отмеченную добычу и меняет силу всех сигналов ползунком.

## Масштаб пространства и запаха

Одна игровая единица равна 0,1 м: клетка мира 256×256 занимает 25,6×25,6 м, а вся территория 10240×10240 — 1,024×1,024 км. Физика перемещения измеряется в реальных секундах; ускоренные игровые часы намеренно остаются отдельной механикой выживания. Управление использует сжатый темп исследования, чтобы непрерывное перемещение по километровой территории оставалось удобным: 3 м/с в скрытности, 10 м/с обычно и короткий выносливостный рывок 18 м/с (≈65 км/ч, ниже зарегистрированного короткого максимума). Базовый запах живой добычи задан как 115 м: для оленя это до 276 м при сильном благоприятном ветре; сильная открытая падаль — до ≈499 м. Эти значения отражают обычное обнаружение добычи около 300 ярдов при подходящем ветре, а не редкие километровые случаи.

Для production-сборки и проверок:

```bash
npm test
npm run test:visual
npm run build
npm run check:server
npm run sprites:animal-actions -- --check
npm run sprites:state-scales -- --check
```

Production-запуск использует небольшой loopback-only Node-сервер: он раздаёт Vite-сборку, принимает обезличенные события и хранит агрегаты в локальной SQLite. После `npm run build` сервер запускается командой `npm start`; параметры находятся в `.env.example`. Сохранения игры при этом не покидают браузер: основной снимок мира записывается в IndexedDB, а `localStorage` используется только как резерв при отсутствии IndexedDB. Телеметрия передаёт только случайные идентификаторы браузера и вкладки, тип события и выбранную сложность — без содержимого сохранения, координат, потребностей или состояния мира.

Страница `/stats` показывает игроков онлайн, активные игровые сессии, медианное и суммарное время игры, дневную активность и последние сессии. `/stats` и `/api/stats` закрыты двумя уровнями: Nginx `auth_request` через `auth.kunini.ru` и серверный allowlist стабильных `X-Auth-User-Id` из `STATS_ALLOWED_USER_IDS`. Пустой allowlist закрывает страницу для всех. Публичным остаётся только строго валидируемый `POST /api/events`; конфигурация для `wildbound.kunini.ru` и порядок установки описаны в `ops/README.md`.

Приглушённые версии всех семи изображений семейства окружения воспроизводимо собираются командой `npm run sprites:terrain-muted`; исходные версии остаются неизменными. Мировые атласы при повторной подготовке нормализуются командой `npm run sprites:world-grid`: она приводит четыре runtime-листа к точной сетке Phaser 1252×1252 и не даёт объектам прозрачных атласов пересекать границы кадров.

Визуальная регрессия проверяет все 640 основных кадров управляемого волка, дополнительные 512 кадров переноса мяса, 128 кадров закапывания, 32 кадра Нивы и Торра, движение четырёх видов добычи, по 96 кадров действий (отдых, кормление и питьё) на каждый вид, 32 кадра ответного удара оленя, 32 кадра защитного рывка кабана и 3 полных уровня видимых ран для каждой позы волка, оленя, вапити и кабана. Общий аудит не допускает пустых кадров, слабопрозрачного фонового мусора, пересечения границ ячеек, неполных runtime-циклов и скачка линии земли при входе в действие или выходе из него; отдельно очищена эталонная модель волка. Лаборатория `npm run audit:animations` дополнительно чередует 1424 пары состояний с одинаковыми направлением, переноской и уровнем ранения; 424 сопоставимые полнокорпусные пары имеют автоматический предел скачка масштаба, а сжатые стойки, лежание, смерть и эффекты остаются на ручном визуальном ревью. Для походки, новых действий добычи и сородичей дополнительно хранятся проверенные обзорные доски со стрелками ожидаемого направления, чтобы перевёрнутые или обращённые назад кадры были заметны при ревью. Тест сравнивает покадровый эталон и отдельно обнаруживает оторванные части тела, выход за границы атласа, скачки опорной точки и схлопывание силуэта. У удара сверху отдельно проверяется анатомическое направление: задние ноги выносятся за таз, а голова остаётся на месте. Раны встраиваются в итоговую текстуру животного и ограничиваются его силуэтом, а не рисуются отдельным игровым объектом. Эталон намеренно обновляется отдельной командой `npm run test:visual:update` только после проверки новых изображений.

## Сложность и новый баланс

Перед стартом выбирается сложность. `SURVIVAL` включён по умолчанию: 14 кроликов, 10 оленей, 5 вапити и 4 кабана; каждый третий день становится скудным, а новые животные приходят только на рассвете или в сумерках, далеко от волка и недавно выбитых районов. Остатки мяса учитываются как биомасса и задерживают восстановление популяции. После двух убийств в одном районе ближайшая добыча мигрирует к дальнему краю территории. Кролик даёт 20 единиц мяса, олень — 65, вапити — 95, кабан — 82.

Атака расходует 20 выносливости. Раны уменьшают максимальный запас сил и скорость, а лечение требует голода и жажды ниже 60. Раненые волк, олень, вапити и кабан переключаются между полными текстурами лёгкой, средней и тяжёлой раны для каждой доступной позы. Неудачный угол атаки на оленя вызывает детерминированный ответный удар задними ногами с отдельной восьминаправленной анимацией. Открытое мясо хранится около шести игровых часов, закопанное — двое игровых суток; незащищённый запас ежедневно теряет 30%, а в скудный день 35% из-за падальщиков. Закапывание длится три секунды, расходует 15 выносливости, допускается только в сухой мягкой почве и не ближе 500 единиц от другого запаса. Территориальные метки защищают не более трёх ближайших запасов.

`EXPLORER` сохраняет прежние 20 кроликов и 22 оленя, дополняет их 10 вапити и 8 кабанами, сохраняет высокий выход мяса, быстрое лечение, свободное размещение запасов и старые сроки разложения. Все приведённые ниже старые численные значения популяции и хранения относятся к этому совместимому режиму. Старое сохранение без поля сложности загружается как `EXPLORER`. Кнопка `FULL RESET` в главном меню удаляет текущую жизнь из IndexedDB и резервного localStorage и только после этого запускает новую с выбранной сложностью.

## Управление

- `WASD` — движение;
- левый клик по живому животному — отметить цель значком хищных челюстей и выделить её запах красным; после смерти животного метка и слежение снимаются;
- `Shift` — бег с расходом выносливости; в пригибании — немедленный выпад из скрытности;
- `C` — включить или выключить пригибание и скрытное движение;
- `E` — атака, еда, питьё или работа с запасом мяса по контексту;
- `Q` — режим обоняния;
- `M` — оставить пахучую территориальную метку в текущем месте;
- `R` — лечь отдыхать;
- `F5` — сохранить игру;
- `F9` — загрузить сохранение;
- колесо мыши — масштаб камеры;
- `Space` или `Esc` — пауза.

`LOG MODE` можно включить перед началом игры в главном меню или в любой момент через меню паузы по `Esc`. В этом режиме справа появляется журнал охоты: он фиксирует реальные переходы восприятия животных — когда олень или кролик увидел, услышал либо учуял волка, насторожился, обратился в бегство или успокоился после потери угрозы. Повторяющиеся события стада объединяются, а журнал хранит восемь последних записей, поэтому он не перекрывает игру непрерывным потоком сообщений. По умолчанию режим выключен. Когда раненый волк полностью улёгся отдыхать, внизу появляется кнопка `T REST UNTIL HEALED`: она пропускает время по обычным правилам восстановления, учитывает рост голода и жажды, продвигает сутки, освещение, ветер, потребности животных, разложение падали и восстановление популяции, а затем поднимает волка.

Мир и животные работают независимо от действий игрока. Управляемый волк использует восемь отдельных рисованных направлений без поворота спрайта; северный и южный ракурсы показаны строго сверху. Для каждого направления предусмотрены отдельные циклы ходьбы, бега, пригибания, скрытного ползучего шага, спокойного ожидания, атаки, еды, питья и закапывания. Контекстное действие блокирует перемещение до завершения одноразовой анимации. Кадры ожидания используют единую опорную точку, поэтому дыхание и небольшие движения не сдвигают волка по экрану. `Shift` включает более быстрый шестнадцатикадровый галоп и расходует выносливость; после отпускания клавиши цикл возвращается к ходьбе с сохранением фазы шага. При истощении волк остаётся на скорости и анимации ходьбы, пока игрок не отпустит `Shift` и не нажмёт его снова после восстановления достаточного запаса сил. Каждый рывок накапливает долг восстановления: после повторного бега выносливость возвращается всё медленнее, а длительный отдых одновременно восстанавливает запас сил и снимает накопленное напряжение. Накопленное истощение дополнительно ускоряет голод и особенно жажду, а при высокой нагрузке начинает отнимать здоровье даже у волка. `C` включает отдельную низкую скрытную стойку и анимацию ползучего шага: волк движется медленнее, создаёт гораздо меньше шума и визуального движения, но запах полностью не исчезает. Нажатие `Shift` в этой стойке сразу отключает скрытность и запускает короткий выпад в бег по текущему направлению. Через 20 секунд обычного бездействия волк автоматически ложится, а новое движение сначала запускает анимацию подъёма. `R` позволяет начать отдых сразу. Кролики, олени, вапити и кабаны также используют восемь отдельных рисованных направлений без поворота изображения, отдельные спокойные циклы ожидания, походку, бегство, четырёхфазные циклы отдыха, кормления и питья и вид тушки для каждого ракурса. Переходные кадры действий выровнены по линии земли с соответствующим ожиданием; фаза походки сохраняется при повороте и переходе между спокойным движением и бегством, а скорость воспроизведения следует фактической скорости животного. Три уровня ранений визуально поддерживаются волком, оленем, вапити и кабаном; кролик с единственной единицей здоровья сразу переходит в тушку. У всех живых животных есть двухслойная мягкая контактная тень, которая остаётся на земле независимо от текущего кадра. Добыча объединяет зрение в широком переднем секторе, слышимость движения и переносимый ветром запах. Сильный ветер вытягивает запах в узкий подветренный след: подход против ветра теперь во много раз слабее для обоняния добычи, тогда как подход с наветренной стороны быстро выдаёт волка. Деревья, камни, брёвна и горы перекрывают обзор, ночь уменьшает его дальность, а несколько слабых сигналов складываются. Олень настораживается даже при слабом дальнем визуальном контакте и помнит тревогу пять секунд после потери волка; начавшееся бегство фиксируется до безопасного окна выхода из погони.

В спокойном состоянии добыча больше не выбирает случайную точку каждые несколько секунд. У каждого животного накапливаются голод, жажда и усталость: олень идёт к открытому кормовому участку, берегу или лесному укрытию, а кролик чаще держится между травяным кормом и защитным покровом и получает часть влаги с пищей. Кормовые клетки покрывают большую часть открытой среды, не истощаются и используются животным по всей площади, а не только в узкой точке центра. На рассвете и в сумерках кормление имеет больший приоритет. Днём кролики, олени и вапити уходят отдыхать в укрытие по разным видовым расписаниям, а олени дополнительно получают короткий предрассветный период отдыха; индивидуальный сдвиг не даёт всему стаду засыпать одновременно. Угроза, сильный голод или жажда сразу прерывают сон. К цели прокладывается маршрут по свободным клеткам; случайное исследование территории остаётся редким поведением при низких потребностях. После тревоги животное возвращается к прежней цели. Во время бегства животное регулярно строит короткий маршрут к безопасной области: выбирает достижимые клетки дальше от хищника, предпочитает места с несколькими выходами и избегает тупиков и углов границы. У каждого животного есть собственное боковое предпочтение маршрута, а близкие олени дополнительно расходятся друг от друга; итоговое направление всегда ограничено полуплоскостью от угрозы. Если прямая линия закрыта стеной, деревьями или скалами, добыча обходит препятствие вместо непрерывного бега в коллайдер. Бегство расходует выносливость и накапливает долг восстановления, но оба вида способны пережить один непрерывный рывок волка. Скорость снижается геометрически вместе с накопленным истощением: олень сохраняет сильное преимущество в начале погони, однако после примерно двух с половиной минут непрерывного бегства становится медленнее идущего волка. Поэтому успешная охота требует длительного преследования либо скрытного сближения, перехвата пути и повторных рывков. Накопленное истощение по-прежнему ускоряет голод и жажду и при крайней длительной нагрузке повреждает здоровье, но обычные переходы между обильными ресурсами больше не приводят к массовой естественной смертности. Полноценный отдых снимает нагрузку заметно лучше короткой передышки; длительный сон волка продвигает те же циклы сна добычи. Голод, жажда и крайнее истощение всё ещё могут привести к редкой естественной смерти; такая тушка остаётся свежей съедобной падалью и участвует в запахах и кормлении стаи. Открытая или переносимая падаль постепенно разлагается примерно за двенадцать минут реального времени, а закопанный запас хранится в пятнадцать раз дольше; остаток мяса и видимость тушки или насыпи плавно уменьшаются. Сытый волк больше не расходует мясо впустую: остатки можно поднять клавишей `E`, перенести и повторным нажатием закопать. При переноске исходная тушка скрывается, а волк переключается на полные атласы с единым свёртком мяса, встроенным в позу за линией челюсти. Варианты охватывают ожидание, ходьбу, бег, скрытное движение, укладывание, отдых и подъём во всех восьми направлениях; размер изображения не зависит от вида добычи. Под шкалой голода постоянно показано, будет ли волк сейчас есть или запасать мясо, а отметка на шкале обозначает порог возвращения аппетита. Закопанный запас защищён от кормления сородичей, сохраняется вместе с игрой и при необходимости выкапывается для еды либо нового переноса. Асимметричная насыпь свежей земли с хвоей, мхом, листьями и камнями визуально смешивается с лесной подстилкой, а её размер различает запас кролика и оленя. При закапывании насыпь размещается с безопасным отступом перед волком и больше не перекрывает его силуэт.

Крупные деревья, камни, брёвна и скалы имеют отдельные физические границы, которые масштабируются вместе с изображением и соответствуют опорной части объекта; волк может пройти за кроной, но не сквозь ствол или каменное основание. Волк перемещается только с клавиатуры: левый клик больше не строит маршрут, а выбирает живого кролика или оленя как цель. Над выбранным животным появляется значок хищных челюстей, его следы становятся красными, а отдельный красный значок волчьих чувств ведёт по этому запаху. После смерти животного метка исчезает, и выделение его запаха сразу отключается. В `EXPLORER` расширенная территория поддерживает 20 кроликов и 22 оленя; в `SURVIVAL` — 14 и 10, а в скудный день — 8 и 6. Популяции восстанавливаются постепенно. Стая, совместная охота и сбор по вою временно выключены единым флагом без удаления реализации. Следы запаха намеренно показывают приблизительную, стареющую информацию, а не точные позиции добычи; направление ветра меняет их распространение. Частицы сохраняют собственную фазу движения при исчезновении старых следов, поэтому шлейф колеблется плавно без перескоков. След держится 22 секунды. Единый периферийный HUD показывает только источники вне экрана в восьми фиксированных направлениях: голубые линии обозначают запах, янтарные дуги — звук, а прозрачность и насыщенность передают силу сигнала. Значки охватывают кроликов, оленей, вапити, кабанов, стаю, падаль, воду, личные территориальные метки и мясные запасы; одинаковые источники одного направления группируются, а выбранное животное остаётся отдельной красной целью. Территориальная метка по `M` живёт одни игровые сутки, видна в режиме обоняния как полупрозрачный отпечаток лапы, отпугивает добычу запахом и сохраняется вместе с игрой; метки управляемого волка зелёные, а модель владельца и цвета позволяет будущим волкам использовать собственные оттенки. Повторную метку можно оставить через 15 игровых минут, а близкая метка того же владельца при этом обновляется. Одновременно поддерживается до 12 активных меток. Недоеденная туша продолжает оставлять отдельный запах падали и перестаёт делать это после полного съедания. Закопанное мясо создаёт постоянную подсказку обоняния в радиусе 2400 игровых единиц, заметно дальше обычного следа, пока запас существует. Слуховой сигнал бегущего животного сохраняет приблизительность, но следует за самим источником звука, а не за устаревшей точкой. Течение основной реки и обоих ручьёв слышно постоянно в пределах дальности слуха; значок направлен к ближайшему участку текущей воды. Автосохранение выполняется каждые 30 секунд, основное хранилище — IndexedDB с резервным использованием localStorage.

Частицы запаха намеренно остаются полупрозрачными, но теперь немного крупнее и контрастнее на лесной подстилке. Метка выбранной добычи сохраняется, пока волк видит само животное на близкой дистанции или улавливает хотя бы один читаемый участок его следа. После восьми непрерывных секунд без обоих сигналов след считается потерянным, метка снимается, а повторное обнаружение до истечения таймера начинает отсчёт заново.

Формат сохранения привязан к версии процедурной территории. Сохранения из версий 0.3.0 и старше не загружаются в 0.4.0, чтобы волк и животные не оказались внутри заново размещённых препятствий или водоёмов.

Полный визуальный аудит животных запускается командой `npm run audit:animations`. Скрипт собирает точные runtime-циклы всех направлений, действий, режимов переноса и уровней ранений, проверяет дрейф опорной точки, пульсацию размера, повторяющиеся позы, швы циклов и вход в действия относительно ожидания, а затем создаёт интерактивную галерею `art-source/animal-animation-audit-v1/index.html` с анимацией и покадровыми контактными лентами. Детерминированная фабрика `npm run sprites:animal-actions` пересобирает двенадцатистрочные action-атласы из сохранённых исходников и отдельный рывок кабана; режим `--check` только сравнивает результат и не изменяет файлы.

## Архитектура

Проект использует TypeScript, Phaser 3 и Vite. Генерация мира, поиск пути, направленная анимация, потребности волка, время суток, ветер, популяции, сохранения и геометрия источника воды отделены от сцены и покрыты модульными тестами. Визуальные материалы созданы специально для Wildbound и не используют ассеты или бренд оригинальной коммерческой игры.

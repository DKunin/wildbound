# Wildbound

Оригинальный браузерный симулятор выживания волка. Лесная территория теперь создаётся детерминированно из текстурных слоёв и занимает 6144×6144 игровых единиц: поляны, лесная подстилка, тропы, основная река, два отдельных ручья, деревья, валуны, брёвна и горные границы образуют связный мир вместо единого фонового изображения. Положение и длина ручьёв зависят от семени мира, а питьё и запах воды работают у каждого источника. Следы, звуки и запахи помогают читать окружающую среду. Логика двух сородичей сохранена, но временно отключена флагом функции; в активной симуляции участвует только управляемый волк. Охотники намеренно не добавлены.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки и проверок:

```bash
npm test
npm run test:visual
npm run build
```

Визуальная регрессия проверяет все 512 кадров управляемого волка и 96 кадров кролика и оленя: восемь направлений, движение, ожидание, атаку, еду, питьё и специальные состояния. Для трёх фаз бега добычи дополнительно хранится проверенная обзорная доска со стрелками ожидаемого направления, чтобы перевёрнутые или обращённые назад кадры были заметны при ревью. Тест сравнивает покадровый эталон и отдельно обнаруживает оторванные части тела, выход за границы атласа, скачки опорной точки и схлопывание силуэта. Эталон намеренно обновляется отдельной командой `npm run test:visual:update` только после проверки новых изображений.

## Управление

- `WASD` или левый клик — движение;
- `Shift` — бег с расходом выносливости;
- `C` — включить или выключить пригибание и скрытное движение;
- `E` — атака, еда или питьё по контексту;
- `Q` — режим обоняния;
- `R` — лечь отдыхать;
- `F5` — сохранить игру;
- `F9` — загрузить сохранение;
- колесо мыши — масштаб камеры;
- `Space` или `Esc` — пауза.

Мир и животные работают независимо от действий игрока. Управляемый волк использует восемь отдельных рисованных направлений без поворота спрайта; северный и южный ракурсы показаны строго сверху. Для каждого направления предусмотрены отдельные циклы ходьбы, бега, спокойного ожидания, атаки, еды и питья. Контекстное действие блокирует перемещение до завершения одноразовой анимации. Кадры ожидания используют единую опорную точку, поэтому дыхание и небольшие движения не сдвигают волка по экрану. `Shift` включает более быстрый шестнадцатикадровый галоп и расходует выносливость; после отпускания клавиши цикл возвращается к ходьбе с сохранением фазы шага. При истощении волк остаётся на скорости и анимации ходьбы, пока игрок не отпустит `Shift` и не нажмёт его снова после восстановления достаточного запаса сил. `C` включает скрытную стойку: волк движется медленнее, не может бежать и создаёт гораздо меньше шума и визуального движения, но запах полностью не исчезает. Через 20 секунд бездействия волк автоматически ложится, а новое движение сначала запускает анимацию подъёма. `R` позволяет начать отдых сразу. Кролики и олени также используют восемь отдельных рисованных направлений без поворота изображения, отдельные спокойные циклы ожидания, походку, бегство и вид тушки для каждого ракурса. Добыча объединяет зрение в широком переднем секторе, слышимость движения и переносимый ветром запах. Деревья, камни, брёвна и горы перекрывают обзор, ночь уменьшает его дальность, а несколько слабых сигналов складываются. Олень настораживается даже при слабом дальнем визуальном контакте и помнит тревогу пять секунд после потери волка; начавшееся бегство фиксируется до безопасного окна выхода из погони.

В спокойном состоянии добыча больше не выбирает случайную точку каждые несколько секунд. У каждого животного накапливаются голод, жажда и усталость: олень идёт к открытому кормовому участку, берегу или лесному укрытию, а кролик чаще держится между травяным кормом и защитным покровом и получает часть влаги с пищей. На рассвете и в сумерках кормление имеет больший приоритет, в менее активные часы — укрытие и отдых. К цели прокладывается маршрут по свободным клеткам; случайное исследование территории остаётся редким поведением при низких потребностях. Угроза всегда прерывает текущую цель, а после тревоги животное возвращается к ней.

Деревья, камни, брёвна и горы имеют физические границы; движение по клику использует A* и прокладывает путь по свободным клеткам. Популяции добычи восстанавливаются постепенно. Стая, совместная охота и сбор по вою временно выключены единым флагом без удаления реализации. Следы запаха намеренно показывают приблизительную, стареющую информацию, а не точные позиции добычи; направление ветра меняет их распространение. След держится 22 секунды, а HUD показывает направление самого сильного запаха и отдельные направления найденных следов. Недоеденная туша продолжает оставлять отдельный запах падали и перестаёт делать это после полного съедания. Слуховая подсказка бегущего животного сохраняет приблизительность, но следует за самим источником звука, а не за устаревшей точкой. Течение основной реки и обоих ручьёв слышно постоянно в пределах дальности слуха; указатель направлен к ближайшему участку воды. Автосохранение выполняется каждые 30 секунд, основное хранилище — IndexedDB с резервным использованием localStorage.

Формат сохранения привязан к версии процедурной территории. Сохранения из версии 0.2.0 не загружаются, чтобы волк и животные не оказались внутри новых препятствий.

## Архитектура

Проект использует TypeScript, Phaser 3 и Vite. Генерация мира, поиск пути, направленная анимация, потребности волка, время суток, ветер, популяции, сохранения и геометрия источника воды отделены от сцены и покрыты модульными тестами. Визуальные материалы созданы специально для Wildbound и не используют ассеты или бренд оригинальной коммерческой игры.
